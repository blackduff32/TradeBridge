# TradeBridge brand assets

The mark combines two record boundaries with an arrow toward agreement. All artwork is original SVG; no Quantara template assets are included.

| Asset | Use |
| --- | --- |
| `../../web/public/brand/mark.svg` | Canonical app mark and favicon, 32-unit view box |
| `logo.svg`, `logo-light.svg` | 96 × 96 standalone dark/light logo |
| `wordmark.svg`, `wordmark-light.svg` | 270 × 48 horizontal lockup |
| `../../web/public/brand/bridge-field.svg` | Original wireframe bridge field used on the entry screen |
| `readme-hero.svg`, `readme-hero.png` | 1200 × 520 README banner |
| `social-preview.svg`, `social-preview.png` | 1200 × 630 social preview artwork |

SVGs are editable source. PNGs provide predictable font rendering on GitHub; they use locally bundled Manrope and IBM Plex Mono. The social preview file is ready for repository Settings → Social preview; creating the file does not update that setting.

Product screenshots in `../screenshots/` are captured from the actual app with synthetic sample data. The banner and social card are branded artwork, not screenshots.

See [design rules](../DESIGN-REFERENCE.md) and the [token contract](../../DESIGN.md).
